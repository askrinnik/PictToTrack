# PictToTrack

Извлечение GPS-геометок из EXIF фотографий и построение трека для навигатора. Дополнительно формируется интерактивная HTML-карта, где все точки показаны на карте OpenStreetMap с эскизами фотографий и маркерами старта и финиша.

## Что делает

Скрипт [extract-geo.mjs](extract-geo.mjs):

1. Читает все файлы `.jpg` / `.jpeg` из подкаталога [Pictures](Pictures).
2. С помощью библиотеки [`exifr`](https://www.npmjs.com/package/exifr) извлекает из EXIF каждой фотографии:
   - широту и долготу (`GPS`);
   - высоту (`GPSAltitude`);
   - время съёмки (`DateTimeOriginal`, при отсутствии — `CreateDate`).
3. Сортирует точки в **хронологическом порядке** по времени съёмки. Если время у фото отсутствует, оно ставится в конец и упорядочивается по имени файла.
4. Формирует два файла результата.

## Результаты

| Файл | Описание |
|------|----------|
| [result_geotags.json](result_geotags.json) | Коллекция узлов: имя файла, путь к эскизу `thumb`, `latitude`, `longitude`, `altitude`, `time` (ISO 8601). |
| [result_track.gpx](result_track.gpx) | Трек в формате **GPX 1.1** — точки `<trkpt>` и `<wpt>` (waypoint на каждое фото) с высотой, временем и именем фото. Открывается любым навигатором и картографическим приложением (Garmin, OsmAnd, Google Earth, Locus и т.п.). |
| `result_thumbs/` | Уменьшенные копии фотографий (ширина 240px), используются картой при наведении и в попапе. |

> **Примечание о формате.** Формата «JPX» для навигаторов не существует (JPX — это изображения JPEG 2000). Стандартный формат треков — **GPX**, он и используется.

## Установка

Нужен Node.js (проверялось на v24). Установите зависимости:

```powershell
npm install
```

## Запуск

```powershell
npm run extract
```

либо напрямую:

```powershell
node extract-geo.mjs
```

После выполнения в корне проекта появятся (или обновятся) файлы `result_geotags.json`, `result_track.gpx` и папка `result_thumbs/` с эскизами. В консоль выводится количество фотографий с GPS и пути к созданным файлам.

## Интерактивная карта

Страница [result_map.html](result_map.html) показывает все точки на карте OpenStreetMap (Leaflet): точки соединены линией трека, при наведении на точку показывается эскиз фото, при клике — попап с эскизом, кликабельным именем файла (открывает оригинал в новой вкладке) и временем съёмки.

Первая и последняя точки трека отмечены особыми маркерами: **Старт** — зелёный маркер с буквой «A», **Финиш** — красный маркер с буквой «B».

Карта загружает данные и эскизы по сети, поэтому её нужно открывать через локальный сервер:

```powershell
npm run serve
```

Затем откройте в браузере `http://localhost:8080/result_map.html` (порт можно задать переменной `PORT`). Перед первым открытием убедитесь, что выполнен `npm run extract` — карте нужны `result_geotags.json` и папка `result_thumbs/`.

## Добавление новых фотографий

Положите новые `.jpg` в каталог [Pictures](Pictures) и снова выполните `npm run extract` — файлы результата будут пересозданы с учётом всех фотографий.
